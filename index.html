Instanced Geometric Canvas Engine

Software-rendered 3D isometric matrix engine utilizing instance transformations, frustum projection, and capped DPR.

A lightweight canvas rendering engine designed for deterministic isometric visualization. Eliminates realtime shadow maps in favor of mathematical directional Lambertian shading, capping DPR at 1.5 to maintain thermal and battery budgets.

Instanced buffer transformations with automatic fallback when static flag (?static=1) is requested.

High-Contrast Token Architecture

Strict CSS custom property token system enforcing WCAG AA contrast ratios and user motion preferences.

Design token architecture utilizing pure CSS variables with zero runtime styling overhead. Employs mathematically verified contrast pairings (minimum 8:1 ratio) and automatic adaptivity to system prefers-reduced-motion queries.
